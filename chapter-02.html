02. 報酬率分佈與風險

ggplot2 × geom_density • 多檔股票風險比較

這張圖展示了四檔科技股的日報酬率分佈。

紅色虛線為平均報酬率，藍色區域為 ±1 標準差區間。

在 R 中，這張圖可以用以下程式碼產生：

library(ggplot2)
library(dplyr)

# 計算日報酬率
returns <- prices %>%
  group_by(ticker) %>%
  mutate(ret = (price_adjusted - lag(price_adjusted)) / lag(price_adjusted)) %>%
  filter(!is.na(ret))

# 繪製密度圖
ggplot(returns, aes(x = ret, fill = ticker)) +
  geom_density(alpha = 0.4, adjust = 1.5) +
  geom_vline(aes(xintercept = mean(ret)), 
             linetype = "dashed", color = "red", linewidth = 0.8) +
  labs(title = "日報酬率分佈比較",
       x = "日報酬率", y = "密度",
       fill = "股票代碼") +
  theme_minimal(base_family = "sans") +
  scale_fill_manual(values = c("#00ff9d", "#ffaa00", "#ff3366", "#6699ff"))
