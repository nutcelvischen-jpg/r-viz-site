05. ggplot2 的三要素

核心概念：data + aes + geom

ggplot2 的哲學很簡單：每一張圖都是由三個基本元素組成。

  • data：你要畫的資料（data frame）
  • aes（aesthetics）：資料如何對應到視覺屬性（x, y, color, size...）
  • geom：你想用的圖形類型（point, line, bar, boxplot...）

詳細拆解

1. data（資料）

ggplot2 接受任何 data frame。建議使用 tidyverse 整理乾淨的長格式資料。

ggplot(data = gapminder)

2. aes（視覺映射）

aes() 決定「資料的哪一欄」對應到「圖上的哪個視覺屬性」。

aes(x = year, y = lifeExp, color = continent, size = pop)

進階用法：

  • aes(color = ifelse(lifeExp > 70, "high", "low")) — 條件式顏色
  • aes(alpha = year) — 透明度隨時間變化

3. geom（圖形）

geom 決定你畫的是點、線、柱狀圖還是箱形圖。

geom_point() + geom_smooth(method = "lm")

常見錯誤

錯誤 1：把 aes 寫在 geom 外面
正確：aes 應該寫在 ggplot() 裡面，或寫在每個 geom 裡面。
錯誤 2：忘記把變數包在 aes() 裡
錯誤：geom_point(x = year) → 正確：geom_point(aes(x = year))
錯誤 3：geom 的順序影響圖層疊加
先畫的 geom 會被後畫的蓋住。

練習題

練習 1
使用 gapminder 資料，畫出 2007 年各洲平均壽命的柱狀圖。
練習 2
在練習 1 的基礎上，加入 geom_text() 顯示數值標籤。
練習 3
使用 aes(color = ifelse(lifeExp > 70, "high", "low")) 畫出散點圖，並自訂顏色。
