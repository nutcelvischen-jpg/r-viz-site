01. 股價走勢與時間序列

ggplot2 × yfinance • 互動式多檔股票比較

這張圖展示了 2025 年 1 月至 6 月四檔科技股的收盤價走勢。

你可以點擊按鈕來顯示/隱藏特定股票，觀察它們之間的相對強弱。

在 R 中，這張圖可以用以下程式碼產生：

library(ggplot2)
library(yfR)          # 或 quantmod / tidyquant

# 抓取資料
tickers <- c("TSLA", "AAPL", "NVDA", "MSFT")
prices <- yf_get(tickers, 
                 first_date = "2025-01-01",
                 last_date  = "2025-06-08")

# 繪圖
ggplot(prices, aes(x = date, y = price_adjusted, color = ticker)) +
  geom_line(linewidth = 1.2) +
  scale_color_manual(values = c("#00ff9d", "#ffaa00", "#ff3366", "#6699ff")) +
  labs(title = "股價走勢比較",
       x = "日期", y = "調整後收盤價",
       color = "股票代碼") +
  theme_minimal(base_family = "sans") +
  theme(plot.title = element_text(size = 16, face = "bold"))
